# Personal portfolio

```bash
npm run dev
```

Open http://localhost:3000.

The public site renders from the seed content until a new Supabase project is connected. Create that project in your own Supabase account, copy `.env.example` to `.env.local`, apply `supabase/migrations/0001_init.sql` in the new project, then run `npm run seed`.

Do not use the Girl's Closet or Nketsiaa databases.
